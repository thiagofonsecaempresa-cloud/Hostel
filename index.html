Backup e portabilidade

Seus dados são seus. Faça cópias e leve-os para outro navegador.

Importante: GitHub Pages hospeda o site, mas não sincroniza os dados entre celulares e computadores. Este sistema salva no armazenamento local do navegador. Use exportação/importação para fazer backup ou transferir dados.

⇩ Exportar todos os dados

Baixe um arquivo JSON com reservas e configurações dos quartos. Guarde-o em local seguro.

⇧ Importar backup

Restaure um arquivo JSON exportado anteriormente. A importação substitui os dados atuais deste navegador.

▦ Exportar tabela CSV

Exporta as reservas para Excel, Google Planilhas ou outros programas de planilha.

⚠ Limpar dados locais

Apaga os dados salvos neste navegador. Exporte um backup antes de continuar.

Configurar quartos

O hostel tem cinco quartos. Ajuste o nome e a capacidade de cada um. A configuração de camas é apenas informativa.
