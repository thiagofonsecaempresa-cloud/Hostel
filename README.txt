# Hostel MK

Sistema web estático de reservas, check-in/check-out e relatórios.
Desenvolvido por Thiago Fonseca.

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie `index.html` para a raiz do repositório GitHub.
3. Abra Settings → Pages.
4. Selecione Deploy from a branch, branch `main` e pasta `/ (root)`.
5. Salve e aguarde a publicação.

## Dados
O sistema salva dados no armazenamento local do navegador. Use a opção Backup e dados para exportar JSON regularmente. Os dados não são sincronizados entre dispositivos.
